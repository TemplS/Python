Для запуска тестов и формирования отчетов нужно:
1. Копируем путь папки с тестами в буфер обмена
2. В терминале запускаем команду "pytest 'ваш путь' --alluredir=./'название файла'" (Все это прописывается без кавычек)
3. Ожидаем результата тестов
4. Дальше сохраняем тесты командой "allure generate 'название вашего файла'"
4.1 Или запускаем сразу отчет "allure serve 'название вашего файла'"
5. Если сохранили данные в папке, то открываем их командой "allure open 'название папки'"
